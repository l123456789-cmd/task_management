## 🌟 核心功能亮点

- **流体感敏捷看板 (Glassmorphism Kanban Board)**
  完全基于毛玻璃特效引擎的跨设备高颜值暗黑式防疲劳界面。原生级流体支持 `HTML5 Drag & Drop`，只需要最直观地动用鼠标拖拽即可无缝将工作扭转推向不同列。
  
- **全系数据聚合与重度多维筛选**
  所有归属地、自定义任务种类以及执行人均能依靠 Vue 的超级响应中心被提取成为实时联动的数据筛选框。真正规避数据查询导致满屏幕混乱。

- **超高自由度附件库 & 物理级磁盘清理引擎**
  提供极其强大的任意批量多文件打包挂载功能。
  - **文档文件**：可在任务明细里一键呼出物理源文流原生安全下载。
  - **图片文件**：在卡组顶端形成绝美阵列墙，双击即调起系统的极致深渊暗色画廊进行巨幅无损缩放。
  - **[重大革新] 深度安全销毁捕杀系统**：不管是您在前台交互中点击“×”剔除掉了传错的冗余附件图片，还是直接霸气销毁掉一整条项目流线，底层驻扎的 Python AI 都将在侦听到事件的第一时间触发！它将彻底抹除该文件存储在真实硬盘上的二进制碎末，不为您的固态储存增加一笔无名的硅基垃圾负担！

- **全视角智能打报机**
  将所有的多线任务按进度阶段切分统计，集 `智能甄选` + `短期定制` + `一键渲染下载 Markdown 文本` + `自动映射生成专业级分卡 Excel 电子工作簿` 与一体的黑魔法按钮。

## 🖱️ 系统操作指南

### 1. 从零起航（新增任务录入规则）
点击带有蓝色微光光晕的 `+ New Task`，在展开的大型模态输入空间录入事件：
- **Project Name (核心航线)**：非常重要的一步！该关键词之后将是生成多维汇总日报以及系统识别同核心的关键羁绊点。
- **Description & Progress (记录与反馈)**：全面解禁超长字符输入量。“今日进展情况”多行大文本域自带报告提取器极权认定。
- **Attachments (锚点附件)**：随意选择，支持所有全系统后缀名。

### 2. 直觉态工作接力流转
只要拖拉卡板到邻旁的版面，所有工作流程底层全部为您摆平并持久存储生效。

### 3. 一键出大招：生成日报神器！
- 用手轻点页面上方的 📊 `生成日报` 入口。
- 把“今明日跟进核点”和“短期发展布局”全数用勾选框进行捕获编排！在文本扩展区自由手敲战术规划。
- **执行引擎组装动作**：通过最下面的 3 个核心执行点（一键复制、独立的 `Markdown 存档下载`，或一键抽取极具价值的企业版 `真实 Excel 多列表`）把今天的成果痛快分发给所有人！

## 💻 启动与部署全指南 (运行命令手册)

项目中已经为您提供了一键自动化拉起脚本（`deploy_windows.bat` / `deploy_linux.sh`）。如果您更希望**手动跨终端分步执行与调试**，本节将提供全透明的系统进程挂载标准命令：

### 🎨 第一步：配置并拉起前端引擎 (Vue + Vite Dev 模式)
在**独立的新终端窗口**中执行，专门用于页面的快速预览与热响应修改：
```bash
# 1. 切换至前端工作目录
cd frontend

# 2. 根据 package.json 抽拉提取全套依赖项积木 (仅首次执行拉取需稍长加载时间)
npm install

# 3. 引燃前端侧热更新引擎底座
npm run dev
```
*(当出现绿色提示语指向 `http://localhost:5173/` 时，表示前台组件库网络端口已暴露，可以借由浏览器打开游玩)*

### ⚙️ 第二步：接载并拉起核心总闸后端 (Python FastAPI 模式)
请在**另开一个平铺式终端页签**中独立操作下面这一套后端核心总链路口：
```bash
# 1. 垂直下沉进入后端物理基底
cd backend

# 2. [初始化部署必做] 重铸环境绝对隔离之墙（生成轻量绿色隔离虚拟层）
python -m venv venv

# 3. [极其关键] 全面穿过墙防，将系统级环境变量封板限定锁死在虚拟沙箱内部：
# 【如果您是在 Windows 系统下执行】:
venv\Scripts\activate.bat
# 【如果您是在 Linux/macOS 系统底下跑】:
source venv/bin/activate

# 4. （装配期）对着根骨要求单全量下载挂靠我们框架底层逻辑：
pip install fastapi uvicorn peewee python-multipart aiofiles

# 5. [终极唤醒] 拉起 Uvicorn 主脑并将之捆绑于 8000 源路口，长驻警戒处理所有并发并发订单！
python -m uvicorn main:app --host 0.0.0.0 --port 8000 --reload
```
🔥 **[生产环境挂载机制小贴士]** 当您看到后方的控制台跳出 `Uvicorn running on http://0.0.0.0:8000` 行文时，结合刚刚跑着的前端页面即宣告上下串联联通成功。而在真正对外发布的商业场景（生产环境），您只需要提前在 Frontend 执行完 `npm run build`，以后只需光溜溜**只开这一路 Python 后端**，即可凭 8000 一个端口实现整盘包容映射运行！
